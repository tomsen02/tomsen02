### 01 — Profile

**ShiZai** (`tomsen-ai`) — agent engineer at an AI startup in Shenzhen.

Research focus: **agent runtime reliability** — the trust boundary where a harness meets other people's agents: streaming dialects, watchdogs, lifecycle adjudication, reconnection & replay.

> Past the process boundary it's someone else's code — version-drifting, untrusted, crash-prone.
> You can't fix it; you can only build the layer that survives it.
> **The robustness of that layer is the floor of the whole system.**

### 03 — Principles

1. **Daily-drive what you patch** — bugs are found in the field, not in the backlog.
2. **Issue-first, minimal diff, zero speculation.**
3. **Three-layer reproduction** — red/green unit test → mock-server e2e → real binary.
4. **Mutation A/B every fix** — tests must bite.
5. **One niche, dug deep** — the boundary layer is the territory.
